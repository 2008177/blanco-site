Who this applies to

Blanco is a private assistant used only by its developer (its "owner"). It is not offered to the public, and it processes only the owner's own accounts.

Data Blanco accesses

  • Gmail (read-only): sender, subject, date and a short text snippet of recent emails.
  • Google Calendar (read-only): titles, times and locations of upcoming events.
  • Google Tasks (read and write): open tasks; tasks are added or completed only when the owner asks.
  • Telegram: messages the owner sends to Blanco's bot, and unread messages in the owner's own chats.

Blanco never sends, deletes, archives or modifies email, and never messages anyone other than the owner.

How the data is used

The data is used only to give the owner their daily brief and to answer the owner's questions. To write the brief and the answers, the relevant data is sent to the Anthropic API (Claude), which processes it and returns the text. Nothing is used for advertising, sold, or shared with anyone else.

Where it is stored

Login tokens, a short-lived cache of the latest data, and the owner's notes are stored on a private server controlled by the owner, readable only by Blanco's service account. The cache is replaced with each refresh.

Google API Services User Data Policy

Blanco's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting Blanco's files from the server removes all stored data.

Contact

Questions about this policy can be raised through this site's GitHub page.
